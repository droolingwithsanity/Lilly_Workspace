## Comparison: `lilly_ai.py.bak.2026-08-03` → `lilly_ai.py.bak.2026-08-03-final`

### Added
1. **Line 87**: `OLLAMA_MODEL = os.environ.get("OLLAMA_MODEL", "fast-recall:latest")`
   - Was hardcoded to `"fast-recall:latest"` (non-existent model)
   - Now reads from container env var `OLLAMA_MODEL=qwen2.5:1.5b`

2. **Lines 6327-6331**: Meta-skill skip logic
   ```python
   if not skill.get("action_type") and not skill.get("type"):
       skill = None
   ```
   - Prevents `_context_aware` (config-only skill with empty `action_type`/`type`) from matching keywords like "dashboard", "admin", "make", "build"
   - These were being treated as `intent_launch` due to falsy `action_type` defaulting to `"intent_launch"`

3. **Lines 16713-16736** (first `vibecode_preview_proxy` at L16660): Content-Length fix
   ```python
   safe_headers = {
       k: v for k, v in resp.headers.items()
       if k.lower() not in ("content-length", "content-encoding")
   }
   ```

4. **Lines 16860-16892** (second `vibecode_preview_proxy` at L16782): Same Content-Length fix
   - Both duplicate functions now strip invalid headers after script injection

5. **Line 16640**: `timeout=60` added to `llama_backend.chat()` call in `vibecode_chat`
   - Default was 25s, causing timeouts for longer LLM responses with `max_tokens=1200`

6. **Lines 15466-15500**: `vibecode_download_project(slug)` endpoint
   - `@app.get("/api/vibecode/download/{slug}")` — serves project as ZIP
   - Skips `.git/`, `__pycache__`, `node_modules/`, `.venv/`
   - Returns `StreamingResponse` with `Content-Disposition: attachment`

7. **Lines 378-400**: Improved Auth0 callback error handling
   - Detects "transaction is missing" error
   - Returns `{"error": "...", "hint": "...", "restart_url": "/api/auth0/login"}`
