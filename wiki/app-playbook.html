How to install, use, and automate with the overlay app

Install Overlay Macros Automation Insomniac Troubleshooting

📲 Installation

Step 1: Install the APK

Download the overlay app to your Android phone:

  • Open http://localhost:8098 in your phone's browser
  • Tap ☰ Menu → Download
  • Or direct: http://localhost:8098/api/apk/download?type=light

Step 2: Grant Permissions

The overlay needs Draw over other apps and Termux Run Command:

  1. Android Settings → Apps → Lilly Overlay → Permissions
  2. Enable "Draw over other apps" / "Display over other apps"
  3. Settings → Apps → Termux → Permissions
  4. Enable "Run command" / com.termux.permission.RUN_COMMAND

Step 3: Enable Termux External Apps

In Termux, run:

mkdir -p ~/.termux
grep -qx 'allow-external-apps=true' ~/.termux/termux.properties || echo 'allow-external-apps=true' >> ~/.termux/termux.properties
# Fully close Termux and reopen it

Step 4: Start the Overlay

Open the Lilly Overlay app. You should see the avatar face and chat bubble. If you see a "Enable Termux Shell Tools" button, tap it to verify the connection.

📱 Using the Overlay

The overlay is a floating window that stays on top of other apps. It shows Lilly's face, a chat bubble, and control buttons.

Buttons

🎤 Mic

Tap to speak. Uses browser mic or Android SpeechRecognizer. Tap again to stop.

⏺ Macro

Start/stop recording a sequence of actions. See Macros section below.

📍 Map

Shows your current GPS location on a map.

📡 Radar

Scans for nearby Bluetooth devices (phones, wearables).

➤ Send

Send a text message to Lilly. Type in the input field and tap Send.

Chat Input

Type or speak commands. Lilly understands natural language:

  • "Open YouTube" — launches app
  • "What's the battery?" — sensor query
  • "Automate Instagram" — starts automation setup
  • "Run morning_routine" — plays a macro
  • "What can you do?" — lists available skills

Drag to Move

Long-press the avatar to drag the overlay around the screen. Double-tap to minimize/maximize.

⏺ Macros (Follow Me)

Macros record a sequence of actions and replay them later. Perfect for repetitive tasks.

Recording a Macro

  1. Press ⏺ in the overlay
  2. Perform actions: tap apps, speak commands, navigate
  3. Each step is numbered automatically
  4. Press ⏹ to stop
  5. Say "Save macro as [name]" to save it

Playing a Macro

  • Voice: "Run [macro name]"
  • Text: Type "run [macro name]" in chat
  • API: POST /api/macro/play

Managing Macros

  • "List macros" — shows all saved macros with step counts
  • "Delete [name]" — removes a macro
  • Macros are saved to macros.json and registered in lilly_skills.json
Note: Macros execute system-level commands (tap, swipe, keyevent). They work across any Instagram APK variant because they don't depend on app internals.

🤖 Automation Setup

Lilly can have a conversation to build social media automations. Just say "Automate Instagram".

Example Conversation

You: Automate Instagram
Lilly: What actions? Likes, follows, comments, or all three?

You: Likes and follows
Lilly: How many of each per run?

You: 30 likes, 10 follows
Lilly: When should I run this?

You: At 6am daily
Lilly: Done! Created 'instagram_automation' with 41 steps.

What Gets Created

  • Config file: config-examples/instagram_automation.json
  • Macro: Saved to macros.json
  • Skill: Registered in lilly_skills.json
  • Schedule: Added to scheduled_tasks.json if you specified a time

Safety Limits

Default limits are conservative to avoid shadowbans:

  • Likes: 20 per run
  • Follows: 5 per run
  • Comments: 3 per run
  • Delay between actions: 2-5 seconds (random)

🔗 Insomniac Integration

Insomniac can trigger Lilly macros via HTTP webhooks.

Setup

  1. In Insomniac, create a new HTTP Request action
  2. Set method to POST
  3. URL: http://localhost:8098/api/macro/play
  4. Headers: Content-Type: application/json
  5. Body: {"name": "instagram_automation"}
  6. Set your schedule trigger (time, charger, etc.)

Example: Run on Schedule

curl -X POST http://localhost:8098/api/macro/play \
  -H "Content-Type: application/json" \
  -d '{"name": "instagram_automation"}'

Schedule via Chat

You can also schedule macros directly in the overlay:

  • "Schedule instagram_automation at 6am daily"
  • "Run morning_routine in 2 hours"
  • "Every 3 hours"

🔧 Troubleshooting

Overlay Not Showing

  • Check Draw over other apps permission is granted
  • Restart the overlay app
  • Check battery optimization is disabled for the overlay

Commands Don't Work

Grant Termux permission:

  1. Settings → Apps → Termux → Permissions → Enable "Run command"
  2. In Termux: echo 'allow-external-apps=true' >> ~/.termux/termux.properties
  3. Close and reopen Termux
  4. In overlay: tap "Enable Termux Shell Tools"

Macro Not Executing

  • Verify Termux permission is granted
  • Check macro steps are valid Termux commands
  • Test individual commands via chat: "Run ls"
  • Check server logs for errors

Mic Not Working

Use the browser mic button in the UI. Background mic requires SSH setup.

TTS Not Speaking

pip install piper-tts
# Check voices exist at lillyos/voices/*.onnx

No Notifications

pkg install termux-api
# Enable Notification Listener in Android Settings > Apps > Termux
