🚀 Quick Start

Lilly runs as a web server on port 8098. Your phone connects to it over HTTP.

1. Server Setup

pip install -r requirements.txt
python lilly_ai.py

2. Phone Setup (Termux)

pkg install termux-api python -y
pip install fastapi uvicorn httpx
python termux_sensor_server.py --port 8099

3. Open the UI

Navigate to http://localhost:8098 in any browser. The overlay floats on your phone.

No SSH required for most features. Voice, chat, skills, and sensors all work over plain HTTP.

📱 Overlay App

The overlay is a floating WebView that shows Lilly's face, chat, and controls.

Buttons

🎤 Mic

Toggle voice input. Uses browser mic or Android SpeechRecognizer.

⏺ Macro

Record a sequence of actions. Press to start/stop recording.

📍 Map

Show current GPS location on a map.

📡 Radar

Scan for nearby Bluetooth devices (phones, wearables).

Radial Menu (Long-Press)

Long-press the bubble to open the radial menu with 4 actions:

💬 Chat (0°)

Open the chat messenger panel.

📖 Wiki (90°)

Open the knowledge base wiki panel.

🧒 Kid Mode (180°)

Toggle Socratic learning mode — avatar asks guiding questions instead of giving answers.

⚙️ Settings (270°)

Open overlay settings.

Chat Input

Type or speak commands. Lilly understands natural language:

  • "Open YouTube" — launches app
  • "What's the battery?" — sensor query
  • "Automate Instagram" — starts automation setup
  • "Run morning_routine" — plays a macro
  • "Open Wiki" — opens the knowledge base panel
  • "Kid mode on" — toggles Socratic learning mode

Camera Vision & Stop Sign Detection

The overlay camera sends JPEG frames to the backend for real-time object detection:

YOLOv8n (Primary)

Ultralytics YOLO detects 80 COCO object classes (person, car, phone, etc). Runs on the vision server at port 8095.

Stop Sign Detector (Haar Cascade)

OpenCV Haar Cascade classifier detects stop signs alongside YOLO. Fires an Android notification when a stop sign is spotted (15s cooldown to prevent spam).

Vision pipeline: Camera → JPEG → /api/vision/browser → YOLO server + Haar Cascade → detections merged into avatar sensor context. Ask "what do you see?" to hear what the camera detects.

🛠️ Skills System

Skills are JSON-defined actions Lilly can perform. She has 136+ built-in skills.

Skill Types

intent_launch

Open an app or website via Android Intent.

shell_command

Run a shell command on the phone via Termux.

prompt_argument

Open a URL with the user's text as a query parameter.

macro

Play back a recorded sequence of actions.

How Skills Work

When you say something like "Open Netflix":

  1. Speech is transcribed (Whisper or browser mic)
  2. Text is normalized and matched against skill aliases
  3. Best match is selected and executed via Termux/Intent
  4. Lilly speaks a canned reply or generates one via LLM

Adding Custom Skills

Edit lilly_skills.json:

{
  "my_action": {
    "action_type": "shell_command",
    "command": "sh",
    "args": ["-c", "echo hello"],
    "label": "My Action",
    "aliases": ["do thing", "run thing"]
  }
}

⏺ Macros (Follow Me)

Macros record a sequence of actions and replay them later. Perfect for repetitive tasks.

Recording a Macro

  1. Press ⏺ in the overlay
  2. Perform actions: tap apps, speak commands, navigate
  3. Press ⏹ to stop
  4. Say "Save macro as [name]"

Playing a Macro

  • Voice: "Run [macro name]"
  • Text: Type "run [macro name]" in chat
  • API: POST /api/macro/play

Macro Storage

Macros are saved to macros.json and registered as skills in lilly_skills.json.

Note: Macros execute system-level commands (tap, swipe, keyevent). They work across any Instagram APK variant because they don't depend on app internals.

🤖 Automation

Lilly can have a conversation to build social media automations. Just say "Automate Instagram".

Example Conversation

You: Automate Instagram
Lilly: What actions? Likes, follows, comments, or all three?

You: Likes and follows
Lilly: How many of each per run?

You: 30 likes, 10 follows
Lilly: When should I run this?

You: At 6am daily
Lilly: Done! Created 'instagram_automation' with 41 steps.

Config Files

Automations are saved to config-examples/ as JSON:

  • config-examples/instagram_automation.json — basic template
  • config-examples-extra/instagram_growth_advanced.json — advanced

Scheduling

Use natural language:

  • "Schedule X at 6am daily"
  • "Run X in 2 hours"
  • "Every 3 hours"

Insomniac Integration

Insomniac can trigger Lilly via HTTP:

POST http://:8098/api/macro/play
Content-Type: application/json

{"name": "instagram_automation"}

🔌 API Reference

Core Endpoints

Method Endpoint Purpose
POST /api/chat Send message, get response
GET /api/sensors Latest sensor readings
POST /api/macro/play Execute macro
POST /api/macro/save Save macro as skill
POST /api/macro/schedule Schedule macro
GET /api/lilly_skills List all skills
POST /api/vision/browser Ingest camera frame (JPEG multipart)
GET /api/vision/browser Latest camera detections (YOLO + stop sign)
GET /api/child_mode Get kid mode status
POST /api/child_mode Toggle kid mode

Example: List Macros

curl http://localhost:8098/api/macro/list

Example: Play Macro

curl -X POST http://localhost:8098/api/macro/play \
  -H "Content-Type: application/json" \
  -d '{"name": "instagram_automation"}'

🔧 Troubleshooting

Commands Don't Work

Grant Termux permission:

  1. Settings → Apps → Termux → Permissions → Enable "Run command"
  2. In Termux: echo 'allow-external-apps=true' >> ~/.termux/termux.properties
  3. Close and reopen Termux

No Notifications

pkg install termux-api
# Enable Notification Listener in Android Settings

Mic Not Working

Use the browser mic button in the UI. Background mic requires SSH.

TTS Not Speaking

pip install piper-tts
# Check voices exist at lillyos/voices/*.onnx
